# LawBid

Новый чистый репозиторий LawBid. Код переносится из старых репозиториев по ТЗ.

- `docs/TZ.md` — ТЗ: как устроен проект и порядок работы. Начинать с него.
- `docs/plan.md` — план переезда.
- `docs/decisions.md` — все принятые решения.
- `docs/legal/` — юридические тексты.
- `shared/localization/` — переводы на все языки и обновления ключей.
- `shared/assets/sounds/` — звуки уведомлений и сообщений.
- `shared/assets/icons/` — иконка приложения.

Папки `apps/` и `backend/` появятся, когда начнётся перенос кода.
