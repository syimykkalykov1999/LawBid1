# Стенд старого приложения

`up.sh` поднимает старое приложение и сервер внутри облачной сессии, `lib.mjs` открывает его в Chromium (390×844, светлая или тёмная тема) и включает режим доступности Flutter, после чего экраны находятся по тексту.

Проверено 11.10: приложение открывается, экран входа и ввод номера работают, сервер отвечает, демо-мир создаётся сам.

Не решено: ввод 6-значного кода входа (`OTP_DEV_FIXED_CODE=true`, код `000000`) из Playwright в поле `AppOtpField` до приложения не доходит, поэтому экраны после входа автоматически пока не снимаются. Номер запрашивать заново после `redis-cli flushall`, иначе лимит кодов.

Ссылка из этого стенда живёт только внутри сессии и снаружи не открывается.
