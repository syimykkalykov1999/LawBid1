# LawBid: журнал решений владельца

Для нового проекта. Здесь собрано всё, что владелец (SiMA) решил, потребовал, отменил или подтвердил в старом проекте Claude за 2–11 октября 2026. Ветка, которая пишет паспорт раздела, читает свой раздел здесь. Старые чаты перечитывать не нужно.

Источники: сводки `plan/obshiy-spisok.md`, `plan/spisok-prosb-05-06-oct.md`, `plan/zaprosy.md`, `plan/handoff-phone-fixes.md`, `plan/dengi-spisok.md`, аудиты 02.10, память проекта и последние ответы тредов. Даты в формате ДД.ММ (2026 год). Паролей, ключей и данных аккаунтов здесь нет.

Обозначения: **Решено**: окончательное решение или требование. **Отменено**: от чего владелец отказался или что поменял. **Не сделано**: просили, но не готово. **Ошибка**: известная открытая ошибка. **?**: не уверен, владельцу подтвердить.

## 0. Общие правила (для всех разделов)

**Решено**
- 07.10. Любое изменение интерфейса начинается с макета в светлой и тёмной теме. Код пишется только после «да» владельца.
- 11.10. Владелец не хочет скриншотов и картинок-макетов: изменения показываются в живой веб-сборке, где можно нажимать (ссылку даёт ветка каркаса). Это заменяет правила про макеты ниже, где они противоречат.
- 07.10. Макет рисуется из настоящего кода приложения, с нашими настоящими иконками. Эмодзи и приблизительные картинки не годятся. Показывать только вид «после». Если нужен вид «до», подписать оба огромными буквами, иначе владелец принимает «до» за новый дизайн.
- 07.10. Наши иконки не менять. Набор иконок: Phosphor Light (02.10).
- 07.10. На кнопках и карточках нет пояснительного текста, нет огромных карточек. Нужна одна маленькая кнопка (как «Продвигать»).
- 07.10. Одно изменение делается во всей системе сразу: сервер, админка, приложение, все роли (клиент, адвокат, помощник), права, уведомления, миграции. Не только экран со скриншота.
- 05.10. Тексты помещаются на всех языках: без переполнения и жёлтых полос, кнопки не прыгают, нижние кнопки не упираются в системную панель Android.
- 05.10. Минимум сотрудников, максимум автоматизации. Платные сторонние сервисы не подключать без согласия («если платные, тогда не надо»).
- 07.10. Почти всё управляется из админки переключателями: каждая защита, каждая функция, каждая цена.
- 07.10. Боевые настройки и боевые команды (AWS, миграции, деплой) запускает только владелец. Ключи никогда не пишутся в чат и в git.
- 07.10. Одна сборка приложения на один круг исправлений. Отдельные APK на каждую мелочь не собирать.
- Ответы владельцу: по-русски, коротко, простыми словами, шаги по одному, текст можно скопировать (не на скриншотах).

## 1. Вход, регистрация, выход

**Решено**
- 04.10. Адвокат регистрируется сам в один шаг: штат + номер лицензии + клятва (фото лицензии необязательно). Одобряется сразу, без запросов к сайтам коллегий. До синей галочки в приложении пишется «Лицензия заявлена», а не «верифицирован» (07.10).
- 05.10. Сверка с реестрами штатов только помечает расхождение для админа и никогда не отклоняет сама. Бесплатный открытый реестр есть только у Нью-Йорка.
- Один номер лицензии нельзя привязать к двум аккаунтам. Номер заблокированного мошенника не регистрируется повторно. Разблокировка возможна, если человек объяснит (05.10).
- 05.10. Клиент-мошенник после бана не создаёт новый аккаунт: проверяются телефон, почта, Apple ID и устройство. IP показывается админу, но в оценку не входит.
- 07.10. Вход и все письма по почте выключаются одним переключателем в админке: «Вход и письма по почте», сейчас ВЫКЛ. Причина: AWS SES не дал доступ на рассылку. Основной вход по SMS.
- 07.10. Ревьюеры магазинов и демо-коды проходят без шага почты. В демо-сессиях не спрашивается код для истории дела, выгрузки данных и удаления аккаунта (да владельца 08.10).
- 05.10. Новые страны открываются переключателем в админке. Сейчас открыты только США. Номер из закрытой страны предлагает лист ожидания.
- 07.10. Защита от расходов на время теста: лимит SMS (100 в день всего, 10 кодов на номер в день). Значения меняются в админке, при запуске их поднимаем.

- 11.10. Помощник входит только по коду с первого экрана. Выбор «Помощник адвоката» на экране роли убрать.
- 11.10. Штаты лицензии адвокат указывает только на шаге «Лицензия». Из профиля поле убрать.
- 11.10. До этапа запуска настоящий Twilio не трогаем. В тестовой сборке любой номер принимается, код подставляется по умолчанию (000000), человек сразу внутри. Настоящие SMS на этапах 4–5, только с тестовыми ключами.

**Не сделано**
- Вход через Google и Apple: OAuth-клиенты не созданы.
- Уведомление о блокировке аккаунта по почте (заблокированный не может войти, push ему не доходит).

**Ошибка**
- Сборка 402231 заставляет клиента подтвердить почту на шаге контактов. Исправлено в коде, нужна новая сборка (07.10).
- Демо-аккаунты не работали дальше входа (сервер их отклонял). Исправление в PR #111 (08.10).

## 2. Лента (вкладка 1)

**Решено**
- 06.10. Фильтр ленты: «Все» + «Юр. посты» + Темы + Штат. В «Выберите темы» первая группа «Юр. посты» («Все юр. посты» / «Только мои темы»). Темы показываются группами, как при выборе квалификации (05.10).
- 06.10. Можно выбрать несколько штатов, и в ленте, и в «Кейсах». Выбранные штаты не показываются плашками: кнопка фильтра становится золотой.
- 07.10. Тема «Посты» убрана из фильтров. Фильтр «Все» у нового аккаунта не пустой (05.10).
- 06.10. Новости выключены, но не удалены.
- 06.10. Тап по открытой вкладке прокручивает вверх и обновляет, как в Instagram.
- 07.10. Подпись поста в ленте: 2 строки + «ещё», тап открывает пост. Подряд идущие пустые строки схлопываются.
- 07.10. Лента в стиле Instagram: пост на весь экран, комментарии шторкой снизу, маленькая кнопка «Продвигать» (EN: Boost).
- 07.10. «Продвигать» есть ТОЛЬКО на карточках в списках (лента и списки постов, рилсов, кейсов). Её нет на экране кейса и внутри открытого поста.
- 07.10. Вложения поста открываются одной плашкой «Посмотреть · N» (EN: View) → шторка снизу. Строк с файлами прямо в посте нет. Так же у рилсов.
- 07.10. Фото открываются на весь экран: зум, закрытие свайпом вниз.
- 07.10. Посты без фото выглядят точь-в-точь как в Threads, с репостом.
- 06.10. Посты без квалификации выглядят как в Instagram.
- 05.10. Сокращённые цифры (1,2K), «Подписаться» рядом с именем, кнопка «Поделиться».
- 02.10. В меню поста нет «Копировать ссылку». У чужих постов свои действия.

**Не сделано**
- Репосты не видны в ленте подписчиков (07.10).
- В постах-Threads нет обсуждения с вложенными ответами (07.10).

**?** Посты с фото: одно поле ввода, заголовок необязателен, в посте 6–8 строк + «Читать полностью». Макет перерисовывался, явного «да» в сводках не нашёл.

## 5. Кейсы и биды

**Решено**
- 05.10. Срочность кейса: гибко / в течение месяца / скоро / срочно / очень срочно, или «к дате» (суд, срок подачи, встреча, подписание, другое). Дату могут сдвинуть клиент и нанятый адвокат, другая сторона получает уведомление. Напоминания за 7, 3, 1 и 0 дней.
- 05.10. Карточка приглашения показывает адвокату досье: город, срочность, бюджет, сколько фото и документов. Сами файлы открываются только после принятия.
- 05.10. Обложки кейсов без фото клиента: готовые наборы обложек.
- 06.10. Принятый бид сразу открывает чат.
- 02.10. Завершение дела подтверждают обе стороны.
- 07.10. Компактные карточки, никаких огромных. «Мой кейс»: одна тонкая строка «Кейс ещё актуален?» с маленькими «Да» и «Закрыть», без карточки продвижения. «Мои кейсы»: компактные строки, свайп влево «Закрыть» / «Удалить», маленькая «Продвигать» на открытых кейсах. У адвоката в профиле одна кнопка «Предложить дело».
- 07.10. Кнопка «Предложить» стоит в одном ряду с «Подписаться» / «Написать».
- Заблокированный (в любую сторону) не видит кейсы, не ставит биды и не пишет по кейсу (аудит 02.10).
- 07.10. Описание необязательно. Неактивные кнопки серые и говорят, чего не хватает.

**Не сделано**
- У клиента нет действия «Архив» для кейса.
- Список кейсов: отрывок текста и число файлов пока не приходят с сервера.

## 9. Подписки, цены, скидки

**Решено**
- 03.10. Цены задаются только в админке («Деньги → Цены», только супер-админ). Это единственный источник: приложение и сайт берут цены с сервера. Новая цена сама создаётся в Stripe. Старые подписчики остаются на старой цене, пока не нажать «Применить к подписчикам».
- Цены: адвокат $99/мес или $999/год, помощник $25/мес, золотая галочка клиента $10/мес. Во время теста цены временно снижены до ~$5–10, при запуске поднимаются и нажимается «Применить к подписчикам».
- 05.10. Конструктор планов в админке: что входит в план, собирается переключателями без кода. Пробный период задаётся в плане.
- 07.10. Скидка показывается так: «$99 / ~~$149~~ месяц −33%». Процент округляется вниз. Если старая цена не выше новой, скидка скрыта (никогда не наценка). Карточку плана не перерисовывать.
- 07.10. Карточка «Без подписки — Бесплатно» убрана.
- 07.10. Оплата: если вернуться без карты, «Подтверждаем карту» не показывается.
- Подписки работают на живом Stripe даже во внутреннем тесте (настоящие списания).
- 05.10. Понятный текст, почему оплата не работает у неподтверждённого адвоката.
- Синяя галочка у адвокатов, золотая у клиентов. Галочка клиента одобряется автоматически.

**Отменено**
- 05.10. Донат в Настройках: не делаем.
- 07.10. В список, но не начинать: сделать все платные функции выключаемыми, чтобы приложение могло стать полностью бесплатным.

**Не сделано**
- Все оплаты на живом Stripe не проверены целиком (подписки, продвижение).

## 10. Продвижение

- 07–08.10. Цены продвижения в админке («Деньги → Продвижение»): за показы, людей, нажатия и действия, отдельно для постов, видео, кейсов и профилей. У каждой модели свой выключатель. Неистраченный остаток сам возвращается на карту (PR #112, не слит).

**Не сделано**
- Продвижение профилей адвокатов: цены задать можно, приложение пока не показывает («скоро»).

## 11. Рефералы, партнёры, демо

**Решено**
- 06.10. Рефералы и партнёры платят ОДИН раз за человека, не каждый месяц. Каждый месяц получают только партнёры стран, и выплаты сами останавливаются в дату «Договор до».
- Реферал: пригласившему адвокату $100 в счёт подписки, новичку −20% на первый месяц, клиентам дни продвижения. Программа сейчас ВЫКЛ, включить после Stripe live.
- 05.10. Партнёрка: $50 за адвоката (первая оплата), $10 за клиента. 14 дней проверки. Вступить можно самому из Настроек.
- 05.10. Партнёры стран под полным контролем владельца, отключаются одной кнопкой.
- 05.10. Демо-режим для блогеров: отдельная база, в настоящую ничего не попадает. Демо-коды выдаются в админке.
- 05.10. Сотрудники «Привлечения» работают по лидам со своей реферальной ссылкой. Только бесплатные источники контактов.
- Блогерам бесплатная подписка по договору на 3–12 месяцев.

**Отменено**
- 06.10. Кнопка «Вывести» для партнёров не одобрена.
- 06.10. Идея автоматической частоты выплат прибыли отменена. Выплаты в Stripe ручные, владелец сам жмёт Pay out.

## 12. Отзывы, жалобы, модерация, защита

**Решено**
- 06.10. Об адвокате отзыв оставляет только клиент с завершённым делом. Клиента может оценить любой.
- 05.10. Защита от мошенников-«адвокатов»: каждая проверка отдельный переключатель в «Верификация → Борьба с мошенниками», есть очередь, «Подтвердить / Запросить ещё / Отклонить». Решения сотрудников записываются навсегда, их не может удалить даже владелец.
- 05.10. LawBid никогда не пишет «проверенный адвокат», только что именно совпало и когда.
