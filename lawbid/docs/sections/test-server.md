# Тестовый сервер (этап 4)

Нужен, чтобы веб-версия приложения (GitHub Pages) работала по-настоящему: вход, все языки, посты, публикация, кейсы, чаты, файлы сохраняются. Боевой AWS не затронут.

## Что внутри
Одна машина, пять контейнеров (`backend/deploy/docker-compose.yml`):
- `api`: сервер из `backend/` (NestJS + Prisma);
- `postgres`: база. В старом коде CockroachDB, здесь обычный Postgres 16 (бесплатно у любых хостингов, миграции склеены в одну: `backend/prisma/migrations/20261011000000_init_postgres`);
- `redis`: очереди и лимиты;
- `s3`: свой маленький S3 для файлов (`backend/scripts/test-s3.mjs`). MinIO больше не публикует бесплатный образ. Подписи не проверяются, только тестовые данные;
- `caddy`: HTTPS (сертификат сам, адрес вида `1-2-3-4.sslip.io`, домен покупать не нужно).

## Правила тестового режима
- вход по любому номеру любой страны, код всегда `000000` (`TEST_SERVER_MODE`, `OTP_DEV_FIXED_CODE`), SMS и почта не отправляются (заглушки);
- Stripe, Twilio, SES, Firebase не подключены, ключей нет;
- все 86 языков и все ключи грузятся из `shared/localization` при каждом старте, если файлы изменились (`scripts/test-server-bootstrap.mjs`);
- секреты создаёт `install.sh` на самой машине (`/opt/lawbid/lawbid/backend/deploy/.env`), в git их нет;
- адрес сайта для CORS: `WEB_ORIGINS` (по умолчанию `https://syimykkalykov1999.github.io`).

## Автообновление
Таймер на машине раз в 2 минуты проверяет GitHub (`main`), при новом коммите пересобирает и перезапускает (`update.sh`). Контейнеры сами поднимаются после сбоя и перезагрузки (`restart: unless-stopped`).

## Не работает в этой версии

- настоящие оплаты, SMS, почта, push.
- админка (`apps/admin`) не поднята.

Перенесено как есть: весь `apps/api`, кроме `test/` (e2e-тесты), `k6/`, `tools/`. Не переносили `/dev/echo` и `tmp-import`. Склейка двух систем подписок из паспорта сервера ещё не сделана, это отдельная задача.
