# Паспорт: сайт и веб-платформа

Источник: `LawBidSite` (сайт lawbid.dev) и веб-сборка Flutter в `LawBid/apps/mobile/tool/web_preview`. Решения: `decisions.md`, раздел 15.

Цель владельца: адвокаты и клиенты заходят через браузер с компьютера или телефона и пользуются тем же приложением. Одна база, один сервер, общие публикации.

Пометки «оставить / убрать / изменить» заполняет владелец. Скриншоты добавит ветка скриншотов (пока ячейки пустые).

## Часть А. Как устроено сейчас

| Что | Где | Как работает |
|---|---|---|
| Рекламный сайт | `LawBidSite`, Next.js 16, статический | Собирается в `out/`, выкладывается на GitHub Pages, домен `lawbid.dev` (`public/CNAME`). Цены подтягивает из админки при сборке (`scripts/fetch-pricing.mjs`, раз в 6 часов). Только английский. |
| Веб-версия приложения | `LawBid/apps/mobile`, Flutter web | Отдельной папки `web/` в коде нет: `build.sh` создаёт её при сборке. Собирается вручную скриптом и выкладывается на `syimykkalykov1999.github.io/lawbid-preview/` как превью, закрыта от поисковиков. Ходит в боевой сервер `api.lawbid.dev`. |
| Сервер | `LawBid/apps/api` | Уже готов принимать браузер: адреса `lawbid.dev` и `www.lawbid.dev` разрешены (`web.allowed_origins`, меняется в админке). Веб-клиент помечается заголовком `platform: web`. |

Итого: сейчас lawbid.dev это рекламный сайт, а приложение в браузере существует только как превью. Решение 07.10 (lawbid.dev = сама платформа на AWS) ещё не сделано.

## Часть В. Приложение в браузере (Flutter web), что работает

Экраны те же, что в приложении, их описывают паспорта вкладок. Здесь только веб-особенности.

- Вид: на телефоне во весь экран, на компьютере телефонная рамка посередине (`tool/web_preview/index.html`). Решение «веб 1:1 как приложение» выполняется. — ☐
- Вход по номеру телефона и SMS-коду работает; автоподстановка кода только на Android. — ☐
- Локальная база в браузере (drift + sqlite в wasm). — ☐
- Голосовые: запись и прослушивание есть отдельной веткой для веба. — ☐
- Звонки: только пока вкладка открыта, звонит сама вкладка, без системного экрана звонка. — ☐
- Reels: видео не сжимается в браузере, загружается как есть. — ☐

## Часть Г. Чего не хватает до веб-платформы

1. **Хостинг на AWS для lawbid.dev.** Сейчас веб-сборка не входит в автовыкладку (`deploy.yml` выкладывает только сервер и админку). Нужна автосборка Flutter web и выкладка на AWS по каждому изменению.
2. **Что показывать на lawbid.dev до входа.** Сейчас без входа приложение сразу ведёт на экран приветствия (`app_router_guard.dart`, «нет токена → /welcome»). Публичной части (профили адвокатов, «направление × штат», публичные посты) нет ни в приложении, ни на сервере.
3. **SEO.** Flutter рисует страницу картинкой, Google её почти не читает, а адреса сейчас с `#`. Для публичной части нужны настоящие HTML-страницы на всех языках с переключателем. Решение, как их делать (отдельный лёгкий рендер на сервере или Next.js-часть рядом с Flutter), ещё не принято.
4. **Куда деть рекламный сайт.** Юридические страницы, приглашения `/r/КОД` и файлы `.well-known` должны остаться на lawbid.dev, иначе сломаются ссылки в магазинах и у партнёров.
5. **Уведомления в браузере.** Firebase запускается без настроек для веба (`push_service.dart`), веб-ключа нет, так что push в браузере не приходит.
6. **Адрес сервера.** Превью ходит в `api.lawbid.dev` напрямую; для платформы на том же домене нужно решить, общий домен или отдельный `api.`.
7. **Компьютер.** На большом экране сейчас телефонная рамка. Если адвокатам нужна широкая раскладка (лента + чат рядом), это отдельное решение; по ТЗ пока 1:1.
8. **Демо-вход.** Превью предлагает входить демо-кодом в боевой базе; для открытой беты нужен вход по настоящему номеру (решено 07.10) и защита от спама SMS.

## Известные ошибки, которые нельзя повторить
- Веб-сборка без `--no-web-resources-cdn` и без своих `drift_worker.js`/`sqlite3.wasm` не запускается: держать как в `build.sh`.
- В веб-сборке не должно быть ключей: собирать только из `config/prod.example.json`.
- Звук в звонке в браузере: свой видеорендерер глушится, звук идёт отдельным потоком (`call_media.dart`), иначе эхо или тишина.
