# Паспорт: общие части приложения

Уведомления, подписки и цены, продвижение, рефералы, партнёры и демо, отзывы, жалобы и блокировки, оплата адвокату.
Решения: `docs/decisions.md`, разделы 8–13. Код: старый репозиторий `LawBid`, `apps/mobile/lib/features/…`.
Макеты «после» для четырёх расхождений и флага: https://claude.ai/artifact/Pc6gsdLux6t21dVhwyAS41 (светлая и тёмная тема). Скриншотов старого вида пока нет: появятся, когда ветка «Перенос LawBid в чистый репозиторий» поднимет старое приложение.

**Как заполнять:** в колонке «Решение» владелец пишет **оставить / убрать / изменить: …**. Пустая клетка = ещё не решено.

- У несистемных категорий не показывать «мёртвый» выключатель Email.

### 2.4. История платежей (`payments_screen.dart`)
| Элемент | Решение |
|---|---|
| Список списаний, пустое состояние, код ошибки | |

**Мусор в коде:**
- Две системы планов: «старые» месяц/год (`legacyPlanOf`, `SubscriptionPlan.monthly/yearly`) и планы из конструктора. Старые нужны только для подписок без плана. Предлагаю не переносить, если таких подписок нет.
- Текст «Выгода … (−20%)» у годового плана зашит в код, а $999 к $99×12 это 15,9%. Считаем из цен, округляем вниз: −15% (решение 07.10).
- Комментарий о помощнике «+$100 в месяц», в решениях $25.
- `plans/presentation/plan_offer.dart` (32 строки) почти пустой.

**Исправленные ошибки, не повторять:**
- Неоплаченный checkout больше не прячет планы; карточка «Без подписки — Бесплатно» убрана.
- Если вернуться из Stripe без карты, «Подтверждаем карту» не показывается.
- Отмену можно снять до конца периода.
