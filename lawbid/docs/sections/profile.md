# Паспорт: вкладка «Профиль»

Источник: `syimykkalykov1999/LawBid`, `apps/mobile/lib/features/profile/` и `features/settings/` (коммит 05a53d8).
Решения владельца: `lawbid/docs/decisions.md`, раздел 7.
Скриншоты: появятся, когда поднимут веб-сборку старого приложения. Пока только текст.
Макеты «после» (светлая и тёмная тема, из настоящих токенов и иконок): https://claude.ai/artifact/JYhLDrrHzEG8R7NygSfFF5

**Как заполнять:** в колонке «Решение» владелец пишет: **оставить / убрать / изменить: …**. Пустая клетка = ещё не решено.

Нижнее меню в коде: Лента / Поиск / золотой «+» (не вкладка, кнопка «Создать») / Моё / Профиль (`core/navigation/shell/bottom_nav_config.dart`, `app_bottom_nav.dart`). «Моё» сюда не входит, у него своя ветка.

## Мусор в коде

- `client_profile_view.dart`, `_ClientBody`: старый профиль клиента со вкладкой «Мои кейсы», «Видно только вам» и заглушкой «ввести номер кейса для отзыва». Показывается только если у клиента пустой @username. Ключей `profile.client.myCases`, `reviews.placeholder.*` нет в переводах. **Предложено убрать целиком** (макет «после» по ссылке выше). Ждёт «да».
- Два способа написать отзыв об адвокате: лист в профиле (`showClientReviewSheet`) и полный экран «Оцените адвоката» (экран 14). **Предложено: оставить один лист** (умеет фото), экран 14 убрать. Ждёт «да» по макету.
- `settings_screen.dart`: комментарий над классом говорит, что «Аккаунт», «Выйти», «Подписка» ещё не сделаны. Это неправда, всё работает.
- `attorney_profile_view.dart`: в описании класса «золотая карточка рейтинга», её убрали 30.09 (рейтинг теперь на вкладке «Отзывы»). Два параметра с `ignore: unused_element_parameter` (`_Counter`, `_QuietButton`).
- Часть текстов профиля и настроек лежит не в таблицах переводов `lawbid/shared/localization`, а в коде (`core/l10n/strings/*.dart`): «Как со мной связаться», «Подписка клиента», «Мои продвижения», «Партнёрская программа», «Приём оплат», «Предложить дело» и другие. При переносе не потерять.

## Исправленные ошибки, не повторять

- 07.10: у своего профиля адвоката счётчик постов отставал («1 Посты» при трёх постах). Свой профиль должен учитывать ещё не сброшенные счётчики, как публичный.
- 07.10: аватар без фото или пока фото грузится был пустым синим кругом. Нужно показывать буквы имени.
- 07.10: длинная плашка практик уходила за край экрана. Сокращать с «…» внутри экрана; ряд плашек при этом прокручивается вбок (откат e0dd59e).
- 07.10: лимиты и форматы загрузки фото брались из кода. Брать из админки (bug 17).
- 05.10: «Мои продвижения» в настройках не было видно. Строка появляется, как только есть первое продвижение.
- 05.10: практики нельзя сохранить пустыми.
